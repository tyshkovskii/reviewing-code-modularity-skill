# Order flow
The CLI and HTTP entry points duplicate the same validation, total calculation, persistence, and receipt sequence. Extract that shared order operation while preserving both existing entry-point exports and transport-specific formatting. Infrastructure is supplied as plain functions by the composition root; keep this arrangement. No new framework, packages, event bus, or asynchronous execution is requested. Failure semantics: validate before effects; save before sending; a send failure propagates after save without rollback. Run `node --test contract.test.mjs` before and after the refactor.
